Before you start

About 10 minutes to set up

Your PC

  • Windows 10 or 11, 64-bit
  • An internet connection
  • No extra software needed. Everything Bastion needs is included in the installer.
  • No administrator access needed. Bastion installs for your Windows user only.
  • For tickets, welcome messages and the word filter to work around the clock, the PC needs to stay on with Bastion running.

Discord

  • A Discord server you own
  • A bot application created in the Discord Developer Portal
  • Server Members Intent and Message Content Intent turned on for that bot
  • The bot invited to your server
  • Your server ID: turn on Developer Mode in Discord, right-click the server icon and choose Copy Server ID

Install

Standard plan

  1. Subscribe

    Choose a plan on the pricing page. Sign in with Discord, pick your server, and copy your license key. It's only shown once.

  2. Download and run the installer

    Run the file you downloaded. Bastion installs and opens on its own, and adds a Start menu entry.

  3. Follow the Setup Assistant

    Paste your bot token and server ID. Bastion checks the bot's permissions before it finishes setup. Then open the License panel and enter your license key.

  4. Start the bot

    Click Start Bot on the dashboard. From then on you can run tickets, moderation, onboarding and announcements from the control panel.

If Windows shows "Windows protected your PC": this can appear for newer apps that Windows hasn't seen many times yet. Click More info, check that the publisher is William Kurtz, then click Run anyway. If the publisher is anything else, don't run the file, and let us know.

Your data

Stays on your PC

What stays local

  • Your settings, history, backups and server snapshots are stored on your PC, in your Windows user's app data folder.
  • Your bot token is encrypted for your Windows user.
  • Bastion doesn't send your server's messages, members or records to us. License checks only send your license key (or, after activation, an installation token), a random installation ID and your server ID.

Updates & uninstalling

  • Bastion updates itself. Updates download from our release server, and each one is checked against the hash published with it before it installs.
  • Updates and reinstalls keep your settings and history.
  • Uninstall from Windows Settings → Apps. Your local data isn't deleted automatically, so you can reinstall without losing anything, or delete it yourself.
  • Uninstalling doesn't cancel your subscription. See how to cancel.
