About

I'm Billy, a self-taught indie developer from Iowa, married with 4 kids. BVNGER is the name I build and play under.

I build Windows tools, games and mods. Bastion started as the control panel for my own Discord server, and now other server owners can run it too.

When I'm not coding I'm usually welding or doing carpentry. The rest of my time goes to my family.
