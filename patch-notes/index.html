Patch Notes

What's new in each release. Bastion updates itself, so you get these automatically. Check your version in Settings, under Check for updates.

  1. 1.0.0 October 1, 2026 Latest

    First release

    Bastion Standard is available to everyone, with a 7-day free trial.

    Included

    • Windows control panel with a guided Setup Assistant and connection checks.
    • Support tickets with claim, close, reopen and protected transcripts.
    • Moderation: member reports, word filter, warnings, timeouts, kicks and bans, with history.
    • Announcements with a live preview, images, role targeting and link buttons.
    • Onboarding: automatic member roles and custom welcome messages.
    • Server management: channels, permission presets and guarded cleanup.
    • Health checks and desktop alerts.
    • Backups: settings backups and server structure snapshots.
    • Automatic updates, checked against a published hash before they install.
